# Exploraciones de interfaz de PataWallet

Vista previa aislada con tres composiciones de Inicio. La propuesta Cronología para Actividad ya fue integrada en la aplicación productiva; esta vista previa conserva solo los conceptos de Inicio. Sus datos son ficticios.

Desde la raíz del repositorio, ejecuta:

```bash
npm exec vite -- --config prototypes/home-designs/vite.config.js --host 127.0.0.1
```

Abre `http://127.0.0.1:4175` para explorar Inicio. Usa el selector superior o las teclas `1`, `2`, `3` y las flechas para cambiar entre propuestas; los datos de esa exploración no se guardan ni modifican los datos reales.
